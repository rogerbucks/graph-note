# W3C SCXML schema — source

**Third-party files, kept unchanged.** These are the ten `.xsd` files of the W3C SCXML 1.0 schema. The conformance suite ([[Graph spec conformance suite]]) validates the graph spec's SCXML export against them (§18 of [[Graph spec model]]).

- **Source:** W3C, *State Chart XML (SCXML): State Machine Notation for Control Abstraction*, Recommendation, 1 September 2015 — https://www.w3.org/TR/scxml/. The schema files are linked from it.
